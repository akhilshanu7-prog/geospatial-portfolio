# Akhilesh Kumar — Geospatial Portfolio

A clean, responsive, static academic/geospatial portfolio website.

## Folder structure

- `index.html` — main page
- `css/style.css` — all visual styling
- `js/script.js` — interactions and dynamic sections
- `data/portfolio.js` — **edit this file for projects, maps, publications and links**
- `assets/profile.jpg` — your profile photo
- `assets/projects/` — project and hero images
- `assets/maps/` — map outputs
- `assets/Akhilesh_Kumar_CV.pdf` — optional CV

## Quick editing

Open `data/portfolio.js`.

Change:
- social links
- email
- project titles/descriptions/tags/images
- map titles/images/captions
- publications

## Run locally

Double-clicking `index.html` will usually work. For the best local preview, use VS Code with the Live Server extension.

## Publish with GitHub Pages

1. Create a public GitHub repository, e.g. `geospatial-portfolio`.
2. Upload the contents of this folder.
3. Go to Settings → Pages.
4. Choose `Deploy from a branch`.
5. Select `main` and `/ (root)`.
6. Save.

Your site will be available at:
`https://YOUR-USERNAME.github.io/geospatial-portfolio/`

## Important

Before publishing, replace:
- `your-email@example.com`
- placeholder social URLs
- placeholder images
- optional CV

No backend, database or build process is required.
